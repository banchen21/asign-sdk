# asign-sdk 文档

爱签（Asign）电子合同 OpenAPI V3.0 的 Rust 客户端库。

## 本目录覆盖什么

- `src/api/` 下按业务域拆分的接口模块清单
- SHA1withRSA + MD5 签名与 form-data 报文的实现位置
- 示例与测试怎么跑

## 本目录不覆盖什么

- 爱签开放平台的接口协议、字段与回调约定 → 爱签官方接口文档
